AI probabilities

Softmax logistic regression on the Uno. The state changes only after a few agreeing samples (hysteresis: 2 up / 5 down).

Device health

Raw sensor readings

Unfiltered: DHT11 before gain/offset, single ADC reads of the LDR and of the one receiver (phototransistor, A1), read twice: laser switched OFF (ambient light only) and ON (ambient + laser). ON − OFF is the laser signal; the AI uses its averaged value.

Learning collect labelled data → train the model → install it → upload
          

        

          
1 · Collect. Record every scenario with its true label (clear, light fog, dense fog) — include the tricky ones: humid but no fog, dark but no fog.

          
2 · Train. The model is trained on a 80/20 split in blocks of consecutive rows, so the test score is honest.

          
3 · Install. Writes model_weights.h (the old one is backed up) and uploads the firmware.

          2) click Scan for hardware changes — Windows Update often installs the CH340 driver by itself (needs internet) ·
          3) otherwise open the vendor page above, download the driver, then either run the installer yourself or put it in the drivers/ folder and click Install here
